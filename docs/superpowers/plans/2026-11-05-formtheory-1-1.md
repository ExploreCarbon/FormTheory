# FormTheory 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the most-used Gravity Forms gaps: Turnstile anti-spam, hidden/consent/html fields, merge tags, redirect confirmations, AJAX submit, multiple conditional notifications, webhooks.

**Architecture:** Keep existing class layout. Add three focused classes (`FormTheory_Merge`, `FormTheory_Spam`, `FormTheory_Webhooks`); extend `FormTheory_Fields::sanitize_config` for new config keys; refactor `FormTheory_Frontend::maybe_submit` into a pure `process( $form, $post, $files ): array` result so both the classic POST path and the new AJAX endpoint share it.

**Tech Stack:** PHP 7.4+, WordPress 6.0+, vanilla JS, PHPUnit 9 + Brain Monkey (dev only).

**Spec:** Previous conversation answer, "My picks for v1.1" list.

## Global Constraints

- PHP 7.4 syntax floor (no enums, no `match`, no readonly props).
- No front-end build step; no runtime Composer deps (dev-only `vendor/` not shipped).
- All new config sanitized in `FormTheory_Fields::sanitize_config`; never trust builder JSON.
- Text domain `formtheory`; hooks prefixed `formtheory_`.
- WCAG 2.2 AA: errors announced via `aria-live`, focus moved to first error, targets ≥24px.
- Bump `FORMTHEORY_VERSION` to `1.1.0`; existing 1.0 configs must load unchanged (missing keys get defaults).

## Review Focus

- Saved 1.0 form (no `notifications`, no `confirmation_type`): must still send old single notification and show message. Test in Task 5.
- Merge tag value containing HTML/newlines in email subject: subject must be single-line plain text (header injection). Test in Task 2.
- Redirect URL merge tags with user input: values must be `rawurlencode`d; off-site redirect only if admin-configured host. Test in Task 6.
- Webhook endpoint down/slow: submission must still succeed; request non-blocking, timeout 5s. Test in Task 7.
- JS disabled: classic POST path keeps working with Turnstile + redirect. Test in Task 8 (manual check list).
